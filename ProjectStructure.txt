# SarkariJobs Portal - Project Structure

This reflects the actual repository layout. The repository root is the web root for local XAMPP.

## 🏗️ Architecture Overview

### MVC Pattern Implementation

**Models (`src/models/`)**
- Handle all database operations
- Contain business logic
- Provide data validation
- Return structured data arrays

**Views (Frontend Pages)**
- Located in repository root (web root in XAMPP)
- Use PHP for dynamic content
- Styled with Tailwind CSS
- Mobile-responsive design

**Controllers (Implicit)**
- Logic embedded in page files
- Handle form submissions
- Manage user sessions
- Process search queries

### Database Layer (`src/db.php`)
- Singleton pattern for connection
- PDO with prepared statements
- Error handling and logging
- Connection pooling

### Configuration (`src/config.php`)
- Centralized settings
- Environment-specific configs
- Security parameters
- Feature toggles

### Utilities (`src/helpers.php`)
- Common functions
- Data formatting
- SEO helpers
- Security utilities

## 🔄 Data Flow

### Frontend Request Flow
1. User visits page (e.g., `/sarkari/jobs` via rewrite to `jobs.php`)
2. Page includes required models
3. Model queries database
4. Data processed and displayed
5. HTML rendered with Tailwind CSS

### Admin Panel Flow
1. Admin logs in (`admin/login.php`)
2. Session validation on each page
3. Form submission to add/edit pages
4. Data validation and sanitization
5. Database update via models
6. Redirect with success/error message

## 🛡️ Security Implementation

### Input Validation
- All forms use `htmlspecialchars()`
- Database queries use prepared statements
- File uploads validated by type and size
- Session tokens prevent CSRF

### Access Control
- Admin pages check session validity
- `.htaccess` files protect sensitive directories
- Database credentials in separate config
- Error reporting disabled in production
